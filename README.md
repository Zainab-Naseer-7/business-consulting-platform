As strictly mandated, **every single file is located directly in the root directory**. Absolutely no subfolders (`src/`, `assets/`, `css/`, `js/`, `components/`, etc.) were created.

```text
Business-Consulting-Platform/
│
├── index.html        # Complete Semantic HTML5 Single-Page Platform
├── style.css         # Deep Burgundy & Champagne Gold Luxury Design System
├── script.js         # Reactive Core: Canvas Visuals, Calculations & LocalStorage
├── favicon.svg       # Brand Crest Monogram Vector Icon
└── README.md         # Full Technical Architecture & Portfolio Guide
```

## ♿ Accessibility & Performance Standards

* **100% Offline Functional**: All icons are pure inline SVGs; all graphs are rendered via native HTML5 Canvas 2D API.
* **Accessible Semantics**: Proper HTML5 tags (`<header>`, `<nav>`, `<main>`, `<section>`, `<footer>`, `role="dialog"`).
* **Keyboard Navigable**: Modals close on <kbd>Escape</kbd>; global search triggers on <kbd>Ctrl + K</kbd>.
* **Zero Layout Shift (CLS)**: Pre-allocated canvas dimensions, fluid flexbox, and responsive CSS grid architectures.
* **Reduced Motion Support**: Fully respects `prefers-reduced-motion: reduce`.
